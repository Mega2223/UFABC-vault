## Definição

Uma rede neural é um grupo de modelos de [[Aprendizado Supervisionado|aprendizado supervisionado]] construídos encima do [[Perceptron|perceptron]], tipicamente uma rede neural é uma cadeia de componentes que usam de perceptrons, funções de ativação e hiper parâmetros afim de alcançar um modelo de classificação para padrões complexos.

De forma geral, redes neurais mais modernas são constituídas de 'camadas' de perceptrons, onde cada camada é um conjunto de perceptrons cujos valores de saída são computados pelas saídas dos perceptrons (que são combinações lineares) e alguma determinada função de ativação. O modelo de camadas é útil pois sabendo que perceptrons de uma mesma camada não tem influência entre si pode-se implementar algoritmos que possuam alto grau de paralelismo.

- [[Redes Neurais Convolucionais|CNNs]]
