## Definição

O conjunto de instrução / _instruction set_ é um conjunto de operações suportadas por um determinado [[CPU|processador]], um programa formado a partir de instruções do processador é um programa em _assembly_, o processo de converter uma língua de mais alto nível para um código de instruções de processador é chamado de [[Compilador|compilação]]. 

Cada arquitetura de processador possui um conjunto de instruções distintos, mas existem operações bem comuns entre as arquiteturas, como as [[Unidade Lógica Aritmética|operações de ULA]], que abordam tanto as operações lógicas quanto as operações aritméticas inteiras.
