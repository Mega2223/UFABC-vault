## Definição

É um [[Conjunto de Instruções|conjunto de instruções]] do computador _Stanford MIPS_, que tende a representar arquiteturas mais modernas de computadores em geral. Tipicamente essas instruções possuem 3 operandos, e são da forma
$$\large C \leftarrow f(A,B)$$
De forma geral, o sistema MIPS presume 32 registradores, com 32 bits cada um.
## Operações Suportadas

### Adição e Subtração de Inteiros
Presume que o sistema aritmético é em complemento de 2
```bash
add a,b,c # a = b + c
```

```bash
sub a,b,c # a = b - c
```
