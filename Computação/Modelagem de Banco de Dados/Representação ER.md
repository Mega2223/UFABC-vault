## Modelo ER

O Modelo ER é um modelo de representação de [[Banco de Dados|banco de dados]], representando a estrutura e o _design_ das relações do banco. Um Modelo ER pode ser graficamente representado por um diagrama ER.

O modelo ER é organizado em 3 tipos de estruturas, entidades, relações e atributos. De forma geral, uma entidade representa um formato de objeto independente representado no banco de dados, atributos representam a estrutura de uma entidade.
