## EDO Linear de Segunda Ordem

Uma Equação Diferencial Ordinária Linear de Segunda Ordem é uma equação do tipo
$$\large P(x) \frac{d^2y}{dx^2} + Q(x)\frac{dy}{dx} + R(x)y = G(x)$$

Onde $\large P,Q,R,S$ são funções reais [[Limite#Continuidade|continuas]]. Para $\large G(x) = 0$, dizemos que a EDO Linear de Segunda Ordem é [[Equação Diferencial Homogênea|Homogênea]]. 

### Caso Homogêneo
Para uma EDO Linear de Segunda Ordem Homogênea, se conhecemos dois pontos em sua solução $\large y_1$ e $\large y_2$ então a combinação linear da forma $\large y(x) = c_1 y_1(x) + c_2 y_2(x)$ é uma solução do sistema.
